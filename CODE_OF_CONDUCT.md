# MarkView Local Code of Conduct

MarkView Local follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and
publishing others' private information are not acceptable in any project space: issues, pull requests, discussions
and commit messages.

## Reporting

For MarkView Local spaces, report unacceptable behavior privately to the maintainer of your checkout. The original
MarkView project's contact is **support@getmarkview.com**; it is not a contact for local modifications.

Maintainers may remove content, warn, or block participants from their project spaces, as described in the Covenant's
enforcement guidelines.
